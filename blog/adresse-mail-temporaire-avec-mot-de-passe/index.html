Adresse mail temporaire avec mot de passe : garder sa boîte privée

Publié le 21 novembre 2026, 3 min de lecture

Sur la plupart des sites de mail jetable, la boîte est publique : il suffit de connaître l'adresse pour lire ses messages. C'est pour cela que beaucoup cherchent une adresse mail temporaire avec mot de passe, pour la garder privée.

Le problème des boîtes publiques

Si vous choisissez une adresse simple comme test@... ou jean@..., d'autres personnes peuvent avoir eu la même idée. Elles verront vos messages, et vous verrez les leurs. Pour un simple code de vérification, le risque est faible. Mais un lien de réinitialisation de mot de passe, lui, peut permettre à quelqu'un de prendre le contrôle du compte créé.

La solution : réserver son adresse

Sur adresse-temporaire.fr, un compte gratuit permet de réserver une adresse. Dès qu'elle est réservée :

  • elle devient privée : vous seul pouvez lire ses messages, même si quelqu'un tape exactement la même adresse ;
  • elle est gardée sur votre compte, vous la retrouvez depuis n'importe quel appareil ;
  • ses messages sont conservés 24 heures, ou 30 jours en Premium.

Et sans mot de passe à retenir

Plutôt qu'un mot de passe de plus, la connexion se fait avec un code à 6 chiffres envoyé sur votre adresse e-mail. Vous tapez le code, vous êtes connecté. Rien à retenir, rien qui puisse fuiter.

Gratuit ou Premium ?

Le compte gratuit réserve une adresse, idéale pour un usage régulier. Le Premium, à 2,99 € par mois, en réserve jusqu'à 100, garde les messages 30 jours et peut les transférer vers votre vraie boîte : pratique si vous utilisez une adresse différente par catégorie de sites.

Créer mon compte gratuit

Comment réserver une adresse, pas à pas

  • sur la page d'accueil, cliquez sur Mon compte ;
  • entrez votre adresse e-mail habituelle et recevez un code à 6 chiffres ;
  • tapez le code : votre compte est créé, sans mot de passe ;
  • choisissez le nom de votre adresse ou gardez l'adresse aléatoire, puis réservez-la.

Votre adresse habituelle ne sert qu'à vous connecter. Elle n'est jamais affichée aux sites où vous utilisez l'adresse temporaire, et nous ne vous envoyons pas de publicité.

Pourquoi la connexion par code est plus sûre

Les mots de passe sont le maillon faible de la sécurité en ligne : on les réutilise, on les oublie, ils fuitent. Avec un code envoyé à chaque connexion, il n'y a rien à voler dans notre base, et personne ne peut se connecter à votre compte sans accès à votre boîte mail habituelle. C'est le même principe que celui utilisé par de nombreuses banques et applications.

Que se passe-t-il si je libère une adresse ?

Quand vous libérez une adresse réservée, ses messages sont supprimés et l'adresse redevient publique. Quelqu'un d'autre pourra alors la réserver ou l'utiliser. Si vous avez créé des comptes avec cette adresse, pensez à changer l'adresse de ces comptes avant de la libérer.

Quelques idées d'utilisation

  • Une adresse « achats » pour les boutiques en ligne où vous commandez de temps en temps.
  • Une adresse « essais » pour tester des applications et des services.
  • Une adresse « jeux-concours » pour participer sans voir votre boîte envahie.

Avec le compte gratuit, vous gardez une de ces adresses. Avec le Premium, vous pouvez toutes les avoir, et en ajouter d'autres, jusqu'à 100. Le Premium peut aussi transférer les messages de chaque adresse vers votre vraie boîte.

Questions fréquentes

Puis-je supprimer mon compte ?

Oui, il suffit d'écrire à contact@adresse-temporaire.fr. Votre compte, vos adresses réservées et leurs messages sont alors supprimés.

Que devient mon adresse si j'arrête le Premium ?

Vos adresses restent à vous, mais les messages ne sont plus gardés que 24 heures. Pour en réserver de nouvelles, il faudra rester sous la limite du compte gratuit.

Besoin d'une adresse tout de suite ?

Votre adresse jetable est prête sur la page d'accueil, sans inscription.
